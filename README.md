# Black-Box-System-Controller

A project for the class MTHE 393 - Engineering Design and Practice - Modelling done by a group of five students in mathematics and engineering. The group was given a single input - single output system with unknown internal dynamics, allowing for an input signal to be applied to the system and an output signal observed as a result. The goal was to assume and verify certain properties of the system and to design a PID controller to stabilize the output. 

The modelling of the system was done in stages, starting with noise filtering. The black box system would not produce clean signals as output but would produce a signal with artificial noise added. A low pass filter was designed in order to remove the high frequency noise which was present. Second the group had to verify a key assumption which is that the system was LTI (linear and time invariant). This means that the systems output is additive and multiplicitive, and that a time shift in the input results in the same time shift in the output. All three properties were verified so the system could be modelled as LTI. The model was developed by first constructing a Bode plot for the system and estimating the zeros and poles of the transfer function. The model parameters were then tuned in order to more closely match system dynamics until the models behaviour closely resembled that of the real system. From this model a PID controller could then be designed. The main goal of the controller was to ensure the system could match a constant input signal with a rise time of 10 seconds and 15 seconds settling time.  

Finally the system is connected to the application of heat regulation by making the assumption the uncontrolled system dynamics are reflective of the electrical system controlling the heater. The controller developed is then interpereted as regulating the electrical power produced when an input voltage is applied to the electrical system. The controller design ensures a fast convergence to the desired power draw with a fast rise time and long term stability.
